# 🏓 ปิงปอง AR

เกมปิงปองสู้กับ AI บนโต๊ะจริงผ่านกล้องมือถือ เล่นบนเว็บได้เลย ไม่ต้องติดตั้งแอป รองรับทั้ง iPhone (Safari) และ Android (Chrome)

**เล่นเลย:** https://ardsaleep-arch.github.io/pingpong-ar/

## วิธีเล่น
1. เปิด [สัญลักษณ์ Hiro](https://ardsaleep-arch.github.io/pingpong-ar/marker.html) แล้วพิมพ์ (ประมาณ 10–12 ซม.) หรือเปิดค้างไว้บนจออีกเครื่อง
2. วางสัญลักษณ์ราบบนโต๊ะ ยืนฝั่งที่อ่านตัวอักษรได้ตรง ๆ
3. เปิดเกมบนมือถือ กด **เริ่มเล่นแบบ AR** แล้วอนุญาตให้ใช้กล้อง
4. ส่องให้เห็นสัญลักษณ์ทั้งแผ่น โต๊ะปิงปองจะโผล่ขึ้นมา
5. ลากนิ้วซ้าย–ขวาเพื่อขยับไม้ แตะหน้าจอเพื่อเสิร์ฟ (ตีโดนขอบไม้ ลูกจะเฉียงมากขึ้น)

ถ้ากล้องมองไม่เห็นสัญลักษณ์ เกมจะหยุดชั่วคราวจนกว่าจะเห็นอีกครั้ง ไม่มีกล้องก็กด **ทดลองเล่น** ได้

## เทคนิค
- [three.js](https://threejs.org) 0.164 วาดฉาก 3 มิติ
- [AR.js](https://github.com/AR-js-org/AR.js) 3.4.8 ติดตามสัญลักษณ์ Hiro (ไฟล์ใน `data/` มาจาก AR.js, MIT License)
- ทั้งเกมอยู่ใน `index.html` ไฟล์เดียว
